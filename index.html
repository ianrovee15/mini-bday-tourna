⚖️ What if players have the same record?

We check these in order and stop as soon as one player is ahead. The top 8 go to the playoffs.

  1. Most wins ranks higher.
  2. Best point difference. Points you scored minus points scored against you.
  3. Most points scored.
  4. Head-to-head H2H If only two players are still tied and they played against each other, whoever won that game ranks higher.
  5. Tougher opponents OPP W Add up the wins of everyone you played against. The bigger the number, the tougher your opponents, and the higher you rank.
  6. Tiebreaker games TB Only if players are still exactly level after everything above. Only those players play, first to 7, no deuce: 2 tied = 1 game, 3 tied = everyone plays the other two 1-on-1, 4 tied = 3 doubles games. Most wins ranks higher, then point difference in those games.
  7. Draw DRAW The organizer can use this instead of tiebreaker games, or for 5+ tied players. It is run on screen in front of everyone, is random, and is saved so it never changes.

The tag next to a name shows what put that player above others with the same record. Tap a tag to see the exact numbers or games behind it.
